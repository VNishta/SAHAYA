# SAHAYA — Teacher-Assisted Adaptive Learning System

**SAHAYA** is an adaptive learning platform designed to help teachers identify students' learning gaps, monitor progress, and provide targeted learning support for students in Classes 6–10.

## Problem Statement

Students in the same classroom have different learning needs. Teachers may find it difficult to identify individual learning gaps and adapt their teaching to every student.

## Our Solution

SAHAYA supports teachers through a simple, data-driven workflow:

- **Teacher-created assessments:** Create short multiple-choice questions with answer keys and concept tags.
- **Student response tracking:** Record whether each student answered correctly, incorrectly, or left a question unanswered.
- **Adaptive recommendations:** Recommend whether students should relearn fundamentals, practise more, or advance.
- **Learning-gap insights:** Identify concepts that may need additional attention across the class.
- **AI teaching assistance:** Provide supplementary explanations and practice suggestions, where supported by the prototype.
